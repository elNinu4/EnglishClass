# Behmanesh.English

A small website for my Grade 9 English class — landing page, games, and (soon) more.

## Pages

- `index.html` — class landing page: word of the day, activity grid, class news, contact.
- `games/index.html` — games hub listing every playable activity.
- `games/acg/index.html` — **ACG (Alphabet Card Game)**: match capital letters to their lowercase partners.
